# 🧠 Brain Tumor Detection Using Deep Learning

A deep learning-based project for classifying brain MRI images. The project includes a trained model and a Python-based application that allows users to upload an image and receive a prediction.

## 📌 Project Overview

Brain tumor detection from MRI images is an important application of medical image analysis. This project explores how deep learning can be used for image classification and prediction.

The application provides an interface where a user can upload a brain MRI image, process it through the trained model, and view the prediction.

## ✨ Features

- 🧠 Brain MRI image classification
- 📤 Image upload functionality
- 🤖 Trained deep learning model
- 🌐 User-friendly web interface
- 📊 Model-based prediction
- 🗂️ Organized dataset and prediction files

## 🛠️ Technologies Used

- Python
- Deep Learning
- TensorFlow / Keras
- HTML
- CSS
- NumPy
- Image Processing
